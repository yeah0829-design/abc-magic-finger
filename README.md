# ABC Magic Finger ✨

給學齡前小孩的英文字母遊戲。打開鏡頭，用食指在空中描出字母，順便學自然發音（phonics）。

**直接玩 → https://yeah0829-design.github.io/abc-magic-finger/**

## 玩法

1. 點 **▶ Start**，允許使用相機
2. 把手舉起來給鏡頭看，畫面會出現一個白色筆尖跟著你的食指
3. 從綠色的 **START** 圈開始，依序把字母上的星星一顆顆碰亮
4. 全部碰完，字母會發光撒彩帶，並唸出發音

目前有 A、B、C 三個字母。

## 關於隱私

**鏡頭畫面不會傳到任何地方。**

手部辨識是用 Google MediaPipe 的模型，模型檔會下載到你的裝置上，整個辨識過程都在瀏覽器裡跑完。這個網站沒有後端、沒有資料庫，收不到任何影像，也沒有任何追蹤或分析工具。

你可以自己驗證：玩的時候把 Wi-Fi 關掉，遊戲照樣能玩。

## 裝置需求

- **iPad / iPhone**：Safari，iOS 16.4 以上
- **電腦**：Chrome、Edge、Safari 都可以
- 第一次開啟要下載約 20MB 的辨識模型，之後瀏覽器會快取
- 沒有鏡頭或不想開鏡頭時，可以直接用手指觸控螢幕（或滑鼠拖曳）描字母

## 設計說明

四歲小孩的手部精細動作還在發展，在空中自由書寫必然歪斜。如果做成「自由寫、程式判斷是哪個字母」，結果會是一直判錯、小孩受挫。

所以這裡做的是**描紅**：字母輪廓和筆順都先畫好，小孩只要依序碰過星星就算成功。判定半徑刻意放寬，而且**不會出現任何「錯誤」提示**——沒碰到的星星就只是還沒亮而已。

## 已知限制

語音使用瀏覽器內建的語音合成，唸 phonics 音素（`/æ/`、`/b/`、`/k/`）不夠標準，目前是用近似拼寫（ah、buh、kuh）讓它唸。要更準確的發音，需要改成預錄音檔。
